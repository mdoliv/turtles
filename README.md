# Code and supporting data for Oliveira et al. (2026)

All relevant code and lightweight files are within the [work](./work) directory.

## Structure

```
work/
-- admixture (ADMIXTURE analyses)
-- bcftools (Genotype calling)
-- dadi (dadi-cli files)
-- dadi-pipe (Auxiliary scripts for dadi analyses)
-- dsuite (Fbranch, ABBA-BABA tests)
-- easysfs (SFS projections)
-- fastqc (FASTQC results for the D. coriacea samples)
-- insert (Insert size distribution)
-- kinship (KING-robust kinship estimation using plink)
-- overlap (Site overlap analysis)
-- pi (Diversity summary statistics)
-- plink2 (PCA analysis)
-- stacks (Mapping depth analysis)
-- triangle (Triangle plots)
```

Large files such as FASTQ, BAM, VCF and some BED files are excluded from this repository.
